# 六级上岸打卡簿

一个覆盖 2026 年 10 月 8 日至 12 月 11 日的纯前端六级备考提醒与打卡网站。考试日为 2026 年 12 月 12 日。

## 功能

- 今日日期、考试倒计时、今日任务与预计学习时长
- 游戏式闯关地图：9 个章节、45 个顺序解锁关卡、经验值、等级与星星
- 每日单词、听力、主线关卡及课程支线逐项勾选
- 每章 5 个完整学习任务与 2 张体力恢复卡
- 烤鸭 TV 六级听力阅读课程的具体方法课、真题讲解、观看时长与课后动作
- 后期阅读及写作翻译课程的预留槽位
- 2021—2026 年真题用途与完整模拟标记
- 五类听力错因记录和统计
- 总分 425+、模考 440—460 的目标策略
- 浏览器本地存储、备份导出和导入
- 手机与电脑自适应，手机端提供固定底部导航
- 支持添加到手机主屏幕，并提供基础离线缓存
- 日期与考试倒计时会在跨午夜、重新回到页面或刷新时自动更新

## 手机使用

用手机浏览器打开部署后的同一个网址即可。iPhone 可以在 Safari 的分享菜单中选择“添加到主屏幕”；Android 浏览器通常会提供“安装应用”或“添加到主屏幕”。

进度使用浏览器本地存储，因此手机和电脑的记录默认各自独立。需要换设备时，可以先导出打卡备份，再在另一台设备导入。实时跨设备同步需要另外接入账号与云端数据存储。

## 本地运行

这是纯 HTML、CSS、JavaScript 项目，不需要安装依赖。

推荐使用任意静态服务器打开项目根目录。例如：

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。

也可以直接双击 `index.html`，但使用静态服务器更接近部署后的效果。

## 部署到 GitHub Pages

1. 在 GitHub 新建一个仓库，把 `index.html`、`styles.css`、`app.js` 和 `README.md` 上传到仓库根目录。
2. 进入仓库的 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. 分支选择 `main`，目录选择 `/ (root)`，然后保存。
5. 等待 GitHub 完成部署后，Pages 页面会显示可访问网址。

打卡数据使用 `localStorage`，因此每个浏览器、每台设备各自保存一份。换设备前请先在网站底部导出备份，再在新设备导入。

## 文件说明

- `index.html`：页面结构
- `styles.css`：浅紫与奶油白视觉样式、移动端适配
- `app.js`：完整学习计划、打卡、休息卡、错因记录和本地存储逻辑
- `.openai/hosting.json`：OpenAI Sites 部署配置；部署 GitHub Pages 时可保留或删除
